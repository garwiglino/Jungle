# Plan non exécuté : turnaround depuis un modèle unique

Entrée proposée : reference-dorsale.png, vue dorsale pleine résolution avec doigts écartés et manche ample Tiger Stripe. Les profils incohérents sont exclus de la génération.

1. Générer un seul GLB texturé via Tripo, sans conversion ni rigging. Modèle attendu par défaut : CLI tripo-v3.1, API v3.1-20260211. Estimation indicative : 30 crédits (image-to-model texturé standard), à confirmer par le dry-run du CLI.
2. Examiner le modèle : cinq doigts, espaces interdigitaux, pouce de main droite, proportions du coude/poignet, volume ample de manche, coutures et manchette. Pas de relance payante automatique.
3. Charger ce GLB dans Blender et produire cinq images portrait 1024×1536 avec caméra orthographique, même échelle, même géométrie et mêmes textures. Script préparé : tools/render_arm_turnaround.py. Orientation initiale à vérifier sur le modèle avant rendu final.

Ce dossier ne contient pas encore de modèle généré. Tripo CLI est absent et son installation demande un accord selon la compétence. Aucun crédit dépensé, aucun envoi de fichier effectué. Aucun rendu cohérent à partir d’un modèle unique ne doit être annoncé comme terminé.
